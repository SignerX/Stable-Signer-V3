## Abstract

We present **Stable Signer V3**, a real-time 4K sign language production system built on **4D Superquadric Splatting**. It addresses three limitations of existing avatars: restricted facial expression, inaccurate identity-specific body deformation, and loss of fine appearance details. **Generalizable Face SQ Splatting** adds transferable deformable primitives for richer expression control; **Test-Time Body SQ Splatting** learns an identity-specific virtual muscle layer for more faithful motion; and **Test-Time Tunneling Super-Resolution** uses TunnelingNet to recover identity-specific high-resolution details. Both test-time modules are optimized once for each signer identity and subsequently operate without reference inputs at inference time. Together, they produce stable, precise, identity-faithful, and real-time 4K signer videos.
