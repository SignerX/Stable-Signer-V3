## Contributions

1. **Generalizable Face SQ Splatting.** We introduce a shared deformable superquadric layer that augments a conventional parametric face with richer, controllable expression while generalizing across signer identities.

2. **Test-Time Body SQ Splatting.** We introduce an identity-specific virtual muscle layer fitted from reference evidence at test time, enabling the generic body template to deform more faithfully for each avatar without retraining the frozen generation backbone.

3. **Test-Time Tunneling Super-Resolution.** We introduce a late independent tunneling path that distills signer-video evidence into persistent spatial memory at test time, improving identity-faithful high-resolution rendering while preserving the original generation path.
